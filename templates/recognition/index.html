  • ✅ Reducción de dimensionalidad con PCA
  • ✅ Clasificación con SVM (Support Vector Machine)
  • ✅ Modelo de red neuronal con TensorFlow/Keras
  • ✅ Interfaz web intuitiva para pruebas en línea
  • ✅ Historial de predicciones y entrenamientos
